# Fuzzle and the Shifting Woods · Project Page

The project page for *Fuzzle and the Shifting Woods*, a browser adventure game by Shane Singh.

**View the page:** https://shay2222.github.io/fuzzle-portfolio/

**Play the game:** https://shay2222.github.io/fuzzle/

**Game source code:** https://github.com/shay2222/fuzzle

## What the page covers

- The story of Fuzzle, his family and the warlock Oink, told with the game's own storybook panels
- The characters and lands, all drawn in code with the Canvas 2D API
- The generative AI dialogue system: how characters' lines are generated from the game's state and checked by a guard layer before the player sees them
- The level generator that regrows a level each time the player falls, with a solver that proves every level can be finished
- Music synthesized at runtime with the Web Audio API
- The developer tools, the JavaScript architecture and the generator contract
